# 我的 Homebrew Tap

这是一个包含各种 Cask 的个人 Homebrew tap。

## 可用的 Cask

| Cask          | 描述                                      | 项目主页                                             |
|---------------|--------------------------------------------------|------------------------------------------------------|
| `typeswitch`  | 一款快速切换输入法的工具。 | [ygsgdbd/TypeSwitch](https://github.com/ygsgdbd/TypeSwitch)   |
| `loon`        | 网络工具。                                  | [Loon0x00/Loon4Mac](https://github.com/Loon0x00/Loon4Mac)     |
